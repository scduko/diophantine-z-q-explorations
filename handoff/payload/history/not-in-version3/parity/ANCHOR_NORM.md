# One norm test for both anchor coordinates

This is a separate proposed source change. It uses the inherited exact
characterization of the seven-witness predicate T in the released
manuscript's `subsec:o8-anchor-proof`. It is not part of the purely
algebraic tangent certificate rule and is not an accepted change yet.

Write R=Z_(2) intersect Z_(3). The inherited characterization is
T(t) iff t belongs to R, where T is the two quaternion norm equations
with seven rational witnesses. Keep the original nonzero constant
C=3^(2^k), generated by the unchanged repeated-squaring chain.

The old anchor consists of

```
C a0 = f0,  C a1 = f1,  T(a0),  T(a1).
```

Replace it by

```
C2 = C^2,
C2 t = f0^2 - 2 f1^2,
T(t).
```

It uses nine private rational variables: C2,t and seven witnesses of T.
It has four quadratic residuals. The old anchor has sixteen private
variables and six quadratic residuals. Predicted source saving: seven
variables and two rows. This is not a measured endpoint saving.

## Local equivalence

For any rational a,b, including zero coordinates, put n=a^2-2b^2.

At 2, if both coordinates are nonzero, the two summands have distinct
valuations 2v_2(a) and 1+2v_2(b). Therefore

```
v_2(n) = min(2v_2(a), 1+2v_2(b)).
```

This is nonnegative exactly when both coordinate valuations are
nonnegative. The same conclusion holds when either coordinate is zero.
If n=0, irrationality of sqrt(2) forces a=b=0.

At 3, unequal coordinate valuations give v_3(n)=2min(v_3(a),v_3(b)).
If the valuations are equal, divide both coordinates by that common
power of 3. Their nonzero residue squares are both 1, and
1-2=-1 is nonzero modulo 3. The same formula follows. Zero coordinates
again satisfy the formula with v_p(0)=infinity.

Thus

```
n belongs to R  iff  a and b both belong to R.
```

Apply this with a=f0/C, b=f1/C. Because C is nonzero, the replacement
forces t=a^2-2b^2. The inherited T characterization proves both
existential implications. No conditions on the elliptic point are needed.

## Witness maps and dependency boundary

The coordinate maps a_i=f_i/C and t=a0^2-2a1^2 are explicit rational maps.
The transfer of the seven quaternion witnesses in either direction is an
existence consequence of the inherited T characterization. No explicit
rational map between those quaternion witness tuples is asserted here.
It would be incorrect to label this as a finite algebraic certificate
operation of the same sort as `tangent_compress` without an additional
accepted rule and its mathematical dependency.

The external theorem dependency is unchanged: the same Koenigsmann
Definition 4 and Proposition 6 application already recorded in the
manuscript identifies T exactly with R. The new work is the elementary
local norm calculation above. This does not reuse the unadopted
height-19 or root-37 proposals.

The proposed module may reference the existing shared constant C and
allocate C2 privately. Its coefficient magnitudes remain at most 24,
the maximum already present in T. All residuals have total degree at
most two. No floating-point evaluation or numerical large constant is
introduced. Complete source instantiation and quartic replay remain
required before a measured saving can be stated.
