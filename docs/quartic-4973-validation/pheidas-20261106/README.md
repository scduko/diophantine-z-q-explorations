# Pheidas attribution update

The Version 4 working manuscript now credits Thanases Pheidas in the introduction
and cites his 2000 article. The attribution is on page 4; bibliography item 74 is
on page 198. The PDF remains 199 pages. The mathematical text is unchanged.

[UPDATE.json](UPDATE.json) records the current manuscript, PDF and inventory
acceptance hashes and the exact build run. [PAPER_BUILD.json](PAPER_BUILD.json)
records a successful pinned Tectonic build with no TeX errors or unresolved
references. [VISUAL_REVIEW.json](VISUAL_REVIEW.json) records inspection of the
two pages containing the additions. The [editorial review](../PHEIDAS_ATTRIBUTION_REVIEW.md)
identifies the evidence for the historical attribution and its scope.

The files in the parent directory describe the earlier Version 4 release.
Existing release assets and research ZIPs are unchanged historical snapshots.
