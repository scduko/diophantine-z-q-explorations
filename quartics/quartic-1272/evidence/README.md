# Historical evidence

These files preserve the source audits and original reconstruction receipts. Their original artifact hashes identify the files reviewed at that time. The portable package changes source-location metadata and regenerates the dependent receipts. See `../PROVENANCE.json` for the exact relationship and `../MANIFEST.json` for the shipped bytes.

The source audits include explicit statements of their scope and dependencies. In particular, the earlier audit's statement that the original 1315-variable archive was unavailable remains true. The new 1272-variable reconstruction does not authenticate that missing archive.

The source proofs and local supplements are mathematical arguments. The source-oracle samples are finite checks. Neither is described as a Lean or kernel-checked proof.
